# Student Digital Portfolio and Credential Verification System Using Blockchain

## Overview

A blockchain-based platform designed to securely store, manage, and verify academic credentials. The system enables students to maintain ownership of their credentials while allowing institutions and employers to verify records transparently.

## Objective

To improve the security, transparency, scalability, and trustworthiness of digital credential management using blockchain technology.

## Technologies Used

* React.js
* Node.js
* MongoDB
* Polygon Mumbai Testnet
* Web3

## Features

* Secure credential storage
* Decentralized verification
* Student-owned digital credentials
* Tamper-resistant records
* Transparent verification process
